FallGuard Twin Swarm v3.1.2 FAST-30
=========================

개요
----
건설현장에 배치된 로봇들이 골조 형성 단계부터 구조물 위/바닥을 이동하며 LiDAR 스캔을 수행하고,
스캔 데이터가 사무실 관리자 모니터의 As-built Digital Twin으로 실시간 반영되는 발표용 3D 웹 시뮬레이터입니다.

v3.1.2 FAST-30 핵심 추가 기능
-------------------
1. 철근 누락/부실공사 검측 장면 추가
   - 설계상 상·하부 2겹 철근이어야 하는 구간을 로봇이 스캔합니다.
   - 실제 스캔 결과는 하부 1겹만 감지되는 것으로 표현됩니다.
   - 관리자 모니터에 'DESIGN: 2 LAYERS / SCAN: 1 LAYER' 불일치가 빨간색으로 표시됩니다.
   - 감사 로그에는 철근 검측 오류와 감리 확인 필요 메시지가 기록됩니다.

2. 관리자 서버 -> 현장 로봇 경고 흐름 추가
   - 관리자 모니터에서 부실시공 의심을 확인합니다.
   - 서버 명령이 현장 로봇으로 전송되는 흐름을 상태 패널과 로그로 표시합니다.
   - 현장 로봇이 해당 구역에 접근해 '작업 중지 / 철근 상부층 누락 의심' 프로젝션을 표시합니다.
   - 인부에게 접근 금지 및 작업중지 메시지를 전달하는 장면을 추가했습니다.

3. 현재 하중/위험도 Heatmap 강화
   - As-built 3D 모델 위에 안전/주의/위험 구역을 색상별로 표시합니다.
   - 초록: 상대적으로 안전한 작업면
   - 노랑: 개구부·하중 주의 구역
   - 빨강: 외측 추락 위험/철근 누락 의심 구역
   - 현장 슬래브 위에도 로봇 프로젝션처럼 색상 오버레이가 표시됩니다.

4. 기존 v3 기능 유지
   - 왼쪽: 실제 건설현장 시뮬레이션
   - 오른쪽: 사무실 관리자 모니터
   - 골조 형성 과정: 빈 현장 -> 기둥 -> 보 -> 슬래브 -> 위험구역 -> 외벽/가림막
   - 로봇이 골조 위와 바닥에서 이동하며 상시 스캔
   - 인부 작업/위험 접근/외벽 추락 시나리오
   - 외벽 앵커 기반 Cocoon Net이 사출되어 작업자를 고치형 그물로 포획/현수 고정

실행 방법
---------
방법 1: index.html 직접 실행
1. ZIP 압축을 풉니다.
2. index.html을 Chrome 또는 Edge 브라우저로 엽니다.
3. 왼쪽의 '자동 시연' 버튼을 누릅니다.

방법 2: 로컬 서버 실행 권장
1. run_server.bat을 더블클릭합니다.
2. 브라우저에서 http://localhost:8000 으로 접속합니다.
3. 왼쪽의 '자동 시연' 버튼을 누릅니다.

주의사항
--------
- Three.js를 CDN으로 불러오기 때문에 인터넷 연결이 필요합니다.
- 브라우저 보안 설정 또는 네트워크 환경에 따라 index.html 직접 실행이 제한될 수 있습니다.
  이 경우 run_server.bat을 사용해 로컬 서버로 실행하세요.
- 철근 누락 검측, 위험도 Heatmap, Cocoon Net은 발표용 개념 시각화입니다.
  실제 안전장치/감리 시스템에는 구조해석, 센서 검증, 데이터 정합, 안전인증이 필요합니다.

권장 발표 포인트
----------------
- 골조 형성 단계부터 로봇이 시공 데이터를 축적하므로, 사무실에서 실시간 감리와 부실공사 조기 발견이 가능합니다.
- 철근 2겹 설계 대비 실제 1겹 감지 장면을 통해 설계도와 실제 시공 상태의 불일치를 직관적으로 보여줄 수 있습니다.
- 현재 하중/위험도 Heatmap은 관리자가 위험 구역을 바로 판단하고, 현장 로봇이 인부에게 직접 프로젝션 경고를 보내는 장점으로 연결됩니다.
- 추락 예방을 1차 목표로 하고, 최후의 보루로 외벽 Cocoon Net 구조를 제안하는 이중 안전 시스템입니다.


[v3.1.2 FAST-30 추가]
- 자동 시연 중 “일시정지” 버튼으로 현재 장면을 멈출 수 있습니다.
- 같은 버튼이 “이어 재생”으로 바뀌며, 누르면 멈춘 시점부터 다시 진행됩니다.
- 수동 단계 버튼을 누르거나 초기화하면 자동 시연 일시정지 상태도 함께 해제됩니다.


FAST-30 수정 내용
- v3.1.2 기능 구조는 유지하고 자동 시연만 약 30초로 압축했습니다.
- 자동 시연 흐름을 로봇 스캔 → 구조 레이어 누적/실시간 분석 → 하중 위험구역 설정 → 현장 빔프로젝터 경고 → 추락자 인식/궤적 계산 → 앵커 투망 발사/고정으로 정리했습니다.
- 이후 추가됐던 보조 발판, 로봇 시점 행동 인식 등 신규 기능은 포함하지 않았습니다.


FAST-30 v2 수정
- 마지막 추락 장면에서 추락 발생과 거의 동시에 궤적 계산/고치형 투망 전개가 시작되도록 수정했습니다.
- 작업자가 오래 떨어진 뒤 포획되는 느낌을 줄이고, 추락 직후 바로 포획·현수 고정되는 연출로 변경했습니다.
