# Image Assets

최종 포트폴리오 웹페이지에서는 **실제 사진, 발표자료 크롭, 시뮬레이션 캡처, 새로 생성할 설명 이미지**를 함께 사용한다.

## Folder Structure

```text
assets/images/
├─ camp/
├─ field-research/
├─ project/
├─ presentation/
└─ evaluation/
```

## Visual Principle

- 실제 사진: 캠프 참여와 현장조사의 사실성
- PPT 크롭: 실제 문제정의·POV·발표 결과물
- 시뮬레이션 캡처: 아이디어를 구체화한 과정
- 생성 이미지: 디자인씽킹과 문제 재정의 흐름 설명
