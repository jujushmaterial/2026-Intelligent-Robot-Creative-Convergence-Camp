## Visual Principle

- 실제 사진: 캠프 참여와 현장조사의 사실성
- 수상 증빙: 평가 결과와 상장 기록
- PPT 크롭: 실제 문제정의·POV·발표 결과물
- 시뮬레이션 캡처: 아이디어를 구체화한 과정
- 재구성 이미지: 원본 자료의 정보를 바꾸지 않고 가독성 향상
- 생성 이미지: 사진만으로 설명하기 어려운 디자인씽킹 흐름 보조

추가 파일명과 공개 기준은 [`../../UPLOAD_GUIDE.md`](../../UPLOAD_GUIDE.md)를 따른다.
