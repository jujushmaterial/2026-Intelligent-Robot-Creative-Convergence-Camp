# Downloads

이 폴더에는 사용자가 원본 결과물을 한 번에 내려받을 수 있도록 배포용 파일을 보관한다.

## Upload File

```text
cheoltongi-fast30.zip
```

- 원본 파일: `1차 시연자료_시뮬.zip`
- 파일명 변경 후 업로드
- 압축 해제본은 `simulation/cheoltongi-fast30/`에 별도로 업로드

ZIP과 압축 해제 파일을 모두 보관하는 이유:

- ZIP: 원본 패키지 다운로드
- `simulation/`: 코드 확인과 브라우저 실행

상세 업로드 방법은 [`../UPLOAD_GUIDE.md`](../UPLOAD_GUIDE.md)를 따른다.
